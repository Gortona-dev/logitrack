# Politica de seguranca

## Credenciais

Nao publique senhas, tokens, `DATABASE_URL`, chaves JWT ou arquivos `.env` neste
repositorio. Configure esses valores apenas nos paineis de deploy ou no ambiente
local.

## Ambientes publicos

Credenciais de demonstracao devem ser temporarias e nunca devem possuir acesso
administrativo real a dados sensiveis.

## Reporte

Caso encontre uma falha de seguranca neste projeto, abra uma issue descrevendo o
problema sem publicar credenciais, dados pessoais ou detalhes exploraveis.
